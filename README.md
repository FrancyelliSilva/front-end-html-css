Projeto acadêmico de uma página web desenvolvido com **HTML5** e **CSS3** puros, simulando o lançamento de um café especial fermentado pela técnica japonesa *Koji*.

## Sobre o projeto

Página única que recria o conceito visual de uma marca de café (Mokaclube), com cabeçalho fixo, barra de cupom promocional, banner principal (hero) com imagem de fundo e botão de chamada para ação. O foco do trabalho foi praticar:

- Estruturação semântica em HTML5
- Layout com **Flexbox**
- **Responsividade** via media queries (desktop / mobile)
- Tipografia com **Google Fonts** (Barlow)
- Ícones via **Flaticon UIcons**
- Uso de imagens otimizadas em formato `.webp`

## Estrutura de arquivos

```
front-end-html-css/
├── index.html              # Estrutura da página
├── styles.css              # Estilos e responsividade
├── logo.webp               # Logotipo da marca
```

## Tecnologias utilizadas

- HTML5
- CSS3 (Flexbox + Media Queries)
- Google Fonts — fonte Barlow
- Flaticon UIcons — ícones de menu, busca, usuário e carrinho

## Responsividade

O layout se adapta a duas faixas principais:

- **Desktop** (acima de 1024px) — menu completo com links de navegação
- **Mobile / Tablet** (até 1024px) — menu compacto com ícones de hambúrguer e busca
